## 📌 Descripción
Este proyecto consiste en el desarrollo de una página web de suscripción a un boletín (newsletter) diseñada con HTML5 y CSS3, enfocada en una interfaz limpia, moderna y responsiva.

La página permite a los usuarios ingresar su correo electrónico para suscribirse y recibir información sobre nuevas colecciones, ofertas exclusivas y promociones especiales. El diseño está centrado en la experiencia del usuario, utilizando una estructura clara, tipografía moderna (Inter de Google Fonts) y una tarjeta visual con sombra para resaltar el formulario.
